# Проекты по кодам

Реестр - файл `~/.claude/proekty.md` (для Codex - `~/.agents/proekty.md`). Это единственное место со списком проектов. Если файла нет, создай его по образцу ниже при первом добавлении.

```markdown
# Реестр проектов

Статусы: активен, ждет (заказчика или решения), пауза, закрыт.

| Код | Проект | Папка | Изменен | Статус |
|---|---|---|---|---|
| ROMASHKA-ERP | Внедрение ERP в ООО «Ромашка» | `C:\project\romashka-erp` | 2026-11-17 | активен |
```

Код - латиница, заглавные, через дефис (заказчик-проект), без пробелов, уникальный.

## Без аргумента: список

Покажи короткую таблицу: код, проект, статус. Сгруппируй по разделам реестра, если они есть.

## С кодом: карточка проекта

1. Найди строку по коду (регистр не важен). Нет такого - предложи похожие коды.
2. Проверь, что папка существует. Нет - скажи и предложи поправить реестр.
3. Прочитай в папке: первые строки `CLAUDE.md` или `AGENTS.md`, блок «Текущий этап» в `progress.md`, колонку «В работе» в `KANBAN.md`.
4. Покажи коротко: что за проект, статус, где сейчас, что в работе, что дальше. Статус в реестре расходится с progress - предложи обновить.
5. Напомни, как открыть сессию в проекте: `cd "<папка>"`, затем запустить агента. Работать над проектом нужно из его папки, иначе не загрузятся его правила.

Код чужого проекта из этой сессии не правь: только читай.

## Изменить реестр

- **Добавить:** спроси название, папку и статус, если их нет в сообщении; код предложи сам. Перед записью проверь уникальность кода.
- **Сменить статус или папку:** правь только эту строку, обнови дату в «Изменен».
