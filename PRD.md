# PRD: скиллы аналитика 1С

Зачем: ученики курса «От хотелки до ТЗ» и коллеги получают наши скиллы одной командой в Claude Code или Codex.

Что входит: chtz (карточка, ЧТЗ, чек-лист), razvedka-1c (разбор алгоритма с проверкой через MCP), test-dannye-1c (тестовые данные с прогоном на откате). README с установкой для Claude Code и Codex и ссылками на полезные скиллы других авторов.

Что не входит: копии чужих скиллов, внутренние коммерческие скиллы компании.

Готово, когда: репозиторий опубликован, плагин ставится в Claude Code, `npx skills add` ставит скиллы в Codex, все три скилла срабатывают на свои фразы.
